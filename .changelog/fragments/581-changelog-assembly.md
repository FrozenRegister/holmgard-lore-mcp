### Added

- Changelog-assembly tooling (#581): `scripts/assemble-changelog.mjs` folds `.changelog/fragments/*.md` into `CHANGELOG.md`'s `## [Unreleased]` section by matching `###` heading, then deletes the consumed fragments. Handles real formatting drift found in the existing fragment backlog: a leading `#`/`##` title line before the first `###` heading is folded into that section instead of landing as a literal (document-corrupting) heading, and a fragment with no `###` heading at all defaults to `### Added`. New `changelog-assemble.yml` workflow runs it — `workflow_dispatch`-only (with a `dry_run` input), not automatic on push, since folding the current ~174-fragment backlog in one shot is a consequential one-time action that should be a deliberate human trigger, not something CI does silently on the next unrelated merge. This PR does not run it against the backlog.
