### Features
- Implemented the `health_degradation` tick hook (#631), previously a stub. It applies a standalone severity-tier escalation model (`minor → moderate → severe → critical`) to untreated `character_injuries`, stepping severity up the longer a wound goes untreated (24h/48h/72h thresholds). Deliberately out of scope per the #631 design decision: numeric HP loss from `bleeding_rate`, and any write to `characters.death_mode`/`dissolution_stage` — the hook is read-only and reports escalation, it never persists it. See the code comment in `src/rpg/handlers/tick-hooks.ts` for the known wall-clock-vs-in-game-time gap in `character_injuries.created_at`.
