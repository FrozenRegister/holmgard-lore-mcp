### Added

- Auto-label PRs by changed file paths, diff size, and diff-based complexity (#572). New `pr-labeler.yml` workflow, three jobs: `surface-labels` uses the official `actions/labeler` action with `.github/labeler.yml` to apply the existing `surface:API/state/utils/build/docs/tests/admin` taxonomy (same labels `issue-tagger.yml` already applies to issues, now driven by actual changed paths instead of keyword heuristics); `size-label` computes `size/XS`–`size/XL` from `additions + deletions`; `depth-label` scores `depth:0`–`depth:4` (same labels the issue tagger uses) from file count, line count, and whether the diff touches a risky path (`schema/migrations/**`, `.github/workflows/**`, `src/do/**`, `wrangler.jsonc`). All three deterministic, no LLM calls. Added the five `size/*` labels to `setup-labels.yml`. Confirmed via #573's own CI run that GitHub's `addLabels` auto-creates a missing label on first use (with a default color) — `setup-labels.yml` is still worth running for the canonical colors/descriptions, but isn't a hard prerequisite. Documented in `docs/ai-automation-pipeline.md` (§14), including a fix to that doc's now-stale `apply-patches.yml` allowlist description (it still said docs-only; the allowlist was widened to `src/**`/`tests/**` in #567/#568).
