### Added

- Auto-label PRs by changed file paths and diff size (#572). New `pr-labeler.yml` workflow: a `surface-labels` job uses the official `actions/labeler` action with `.github/labeler.yml` to apply the existing `surface:API/state/utils/build/docs/tests/admin` taxonomy (same labels `issue-tagger.yml` already applies to issues, now driven by actual changed paths instead of keyword heuristics), and a `size-label` job computes `size/XS`–`size/XL` from `additions + deletions` on the PR. Both are deterministic, no LLM calls. Added the five `size/*` labels to `setup-labels.yml`. Documented in `docs/ai-automation-pipeline.md` (§14), including a fix to that doc's now-stale `apply-patches.yml` allowlist description (it still said docs-only; the allowlist was widened to `src/**`/`tests/**` in #567/#568).
